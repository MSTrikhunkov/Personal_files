# План backport-исправлений для OpenSearch Dashboards 2.14.0

Цель: сохранить версии, CommonJS/ESM entry points и штатные API, исправляя только уязвимые алгоритмы.

1. Сопоставить CVE с первичными CNA/advisory и зависимостями yarn.lock; сохранить доказательства.
2. Воспроизвести дефекты на точных npm-версиях из архива на Node 18.19.0.
3. Добавить проверяемые по SHA-256 backport-рецепты и общий идемпотентный установщик.
4. Подключить установщик в postinstall и после production install, до упаковки.
5. Исправить js-yaml 3.13.1/3.14.1/4.1.0; lodash/lodash-es 4.17.21; nanoid 3.3.2/3.3.3; decode-uri-component 0.2.2.
6. Проверить регрессии, неизменность обычного поведения, повторное применение, вложенные копии и отказ на изменённом исходнике.
7. Сформировать последовательные unified diff, проверить применение и откат; описать неприменимость и пределы проверки.
