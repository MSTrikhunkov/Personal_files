# Исправления безопасности python-sqlparse 0.5.4

Дата: 2026-09-16. Все пять запрошенных CVE применимы к коду предоставленного архива. Оснований для заключения о неприменимости нет. Подготовлено пять коммитов и пять патчей командой `git format-patch`; анализ каждой CVE находится в одноимённом файле `.md`.

Исходный архив: `0.5.4.tar.gz`, SHA-256: `e38bdaabaf1376284ed4f97b6101bc008445f4e2474cadd012dba5288d48808d`.
Рабочий Git-репозиторий: `../sqlparse-0.5.4`, базовый тег `baseline-0.5.4`.
Номер версии сохранён; это выборочный перенос security-исправлений, а не обновление всей библиотеки до 0.6.0.

Точный список файлов по порядку находится в `series`. Патч 0003 объединяет первоначальное исправление и последующий upstream-fix токенизации; перенос одного первоначального коммита привёл бы к регрессии. Ссылки на все шесть исходных коммитов есть в сообщениях коммитов и отдельных отчётах. Исходные upstream-патчи сохранены в `upstream/` только для аудита — применять нужно пять патчей из корня этого каталога.

## Применение

Из корня свежей распаковки 0.5.4, уже содержащей исходный Git-коммит:

```sh
git am /absolute/path/to/security-fixes/000*.patch
python -m pytest -q
python -m flake8 sqlparse/
```

Если Git ещё не инициализирован, перед `git am` выполните `git init`, `git add .`, `git commit -m 'Import sqlparse 0.5.4'` с настроенными user.name/user.email. Для применения без Git допустим последовательный `patch -p1`, но проверялась именно команда `git am`.

## Проверки

- CPython 3.9.6, pytest 8.4.2, flake8 7.3.0, macOS.
- Исходный архив: **477 passed, 2 xfailed, 1 xpassed**.
- Пять новых регрессионных проверок ожидаемо падают до исправлений; журнал `evidence/regressions-before.txt`. В этом журнале дополнительные тесты ещё находились в общем файле; в патчах они разделены по CVE.
- После применения серии к отдельной свежей распаковке: **492 passed, 2 xfailed, 1 xpassed**. Неожиданно проходящий старый тест и два xfail не добавлены патчами.
- `flake8 sqlparse/`, `git diff --check` и чистота рабочего дерева проверены; полученный набор файлов побайтно совпал с деревом, из которого экспортированы патчи. Полный журнал: `evidence/apply-and-tests.txt`.
- Матрица Python 3.8–3.14 через pixi и исполнение сгенерированного PHP не проверялись. Исправление output.py проверено upstream-тестами строк вывода.

Производственные изменения соответствуют выбранным hunks апстрима. Отличия переноса: контекст старой версии, перенос двух длинных строк output.py под flake8, исключение посторонних записей CHANGELOG и добавленные тесты числа обходов. Upstream benchmark-скрипты доступны в сохранённых исходных патчах; локальные сопоставимые замеры выполняет `benchmark.py`.

## Замеры

`benchmark.py` принимает путь к исходникам, использует ограниченные размеры входа и медиану трёх запусков. Лексер измеряется отдельно для CVE-2026-59893, остальные векторы — через публичный parse/format. Это экспериментальные измерения на одной машине, не гарантия времени выполнения и не полный аудит сложности библиотеки. Результат «после» измеряет всю серию патчей.

```sh
python security-fixes/benchmark.py /path/to/pristine/sqlparse-0.5.4
python security-fixes/benchmark.py /path/to/patched/sqlparse-0.5.4
```
