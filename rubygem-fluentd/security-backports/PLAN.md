# План backport для Fluentd 1.16.2

Требования: два CVE, upstream как основа, без обновления версии и зависимостей,
сохранение существующих конфигураций, API и форматов кроме опасного поведения.

1. Проверить advisory GHSA-j9cw-hwqf-85w7 / GHSA-pr7j-96cj-549h и PR 5393 / 5392.
2. Сохранить чистый тарбол в локальном Git, tag pristine-1.16.2.
3. CVE-2026-44160: перенести тесты HTTP gzip/deflate и Forward, убедиться,
   что исходная версия принимает превышающий лимит payload. Перенести Extractor
   без zstd, добавить необязательные параметры лимита (256 MiB), сохранить
   прежние позиционные аргументы Handler. Покрыть multi-member gzip и IO.
4. Запустить тесты затронутых путей, создать отдельный git commit.
5. CVE-2026-44025: тестировать HTTP debug/with_ivars с настоящим secret-параметром;
   сохранить маскированный config и безопасный retry; запретить query обходить
   явно отключённые include_config/include_retry; opt-in include_debug_info.
   Проверить штатные метрики и прежние запросы, создать отдельный git commit.
6. git format-patch, git am на свежую распаковку, повтор тестов; записать
   применимость, отличия от upstream, ограничения совместимости и результаты.
